# גיבוי חכם

אפליקציית אנדרואיד (עברית, RTL) לגיבוי ושחזור של אפליקציות עם הנתונים שלהן.

## איך זה עובד
- **חיבור ישיר (מומלץ):** האפליקציה מתחברת בעצמה למכשיר דרך ניפוי באגים אלחוטי, כמו Shizuku.
  התאמה חד-פעמית עם קוד, שמוקלד בהתראה (בלי פיצול מסך), ואחר כך חיבור אוטומטי. אין שרת ADB ואין קובץ בינארי.
  המימוש בספריית libadb-android (קובץ יחיד: `src/libadb/.../LibAdbBackend.kt`), עם יומן חיבור מפורט באפליקציה.
- חלופות: **Shizuku** (בלי Root), או **Root** אם יש.
- אם רכיב החיבור הישיר לא מתקמפל, ה-workflow בונה אוטומטית גרסה בלעדיו (`-PwithLibAdb=false`).
- גיבוי = קובץ ZIP אחד: קובצי APK (כולל Split), נתוני `Android/data`, `Android/media`, OBB,
  ונתונים פרטיים (Root, או אפליקציות debug), יחד עם `manifest.json` ובו סכומי SHA-256.
- הנתונים עוברים ישירות מהמערכת אל ה-ZIP, בלי עותקים זמניים.
- העבודה רצה כשירות קדמי (Foreground Service) עם התראה, ואפשר לבטל אותה.
- לפני שחזור כל קובץ נבדק מול סכום הבדיקה, וקובצי TAR נבדקים מול נתיבים מסוכנים וקישורים.

## בנייה
GitHub Actions (`apply-update.yml`) בונה APK חתום ומעלה אותו כ-Artifact בשם `SmartBackup-APK`.
המפתח (`app/smartbackup.jks`) נשמר בריפו, כך שכל גרסה חדשה מתעדכנת מעל הקודמת.

## מבנה
- `shell/` – חיבור ל-Shizuku / Root והרצת פקודות (דרך pipes).
- `backup/` – מנוע הגיבוי, מנוע השחזור, בדיקת TAR.
- `jobs/` – שירות הרקע ומצב העבודה.
- `ui/` – מסכי Jetpack Compose.
