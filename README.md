# ADB חכם – ממשק עברי מבוסס LADB

אפליקציית Android בעברית ובעיצוב בהיר כחול, המבוססת על מנוע ה־ADB האלחוטי של LADB מאת Tyler Nijmeh.

## יכולות
- חיבור ADB אלחוטי דרך Android Wireless Debugging.
- פעולות מהירות ופקודות מוכנות.
- מסוף ADB ידני והיסטוריית פקודות.
- סוכן Gemini שממיר בקשות בעברית לפקודות ADB ומציג אותן לאישור לפני ביצוע.
- מפתח API נשמר מוצפן באמצעות Android Keystore.

## בנייה
הקוד המלא נמצא בריפו. ה־workflow בשם **Build release APK** בונה APK חתום שניתן להתקין ישירות, ומעלה אותו כ־Artifact של GitHub Actions.

## הגדרת AI
יש להוסיף מפתח Gemini אישי דרך מסך ההגדרות באפליקציה. אין לשמור מפתחות API בקוד המקור או ב־GitHub.

## רישוי
מנוע LADB מבוסס על הפרויקט של Tyler Nijmeh. יש לשמור את הודעות זכויות היוצרים והרישיון המקורי של LADB ואת רישיונות התלויות.
