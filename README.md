# ADB חכם – גיבוי ושחזור אפליקציות + LADB

אפליקציית Android בעברית המבוססת על מנוע ה־ADB האלחוטי של LADB. מסך הבית החדש ממקם את גיבוי ושחזור אפליקציות במרכז, תוך שמירה על כלי ה־ADB, מסוף הפקודות, מנהל האפליקציות, פקודות מוכנות וה־AI שהיו קיימים.

## גיבוי ושחזור
- בחירת אפליקציה מותקנת לפי שם או package id.
- יצירת ZIP נייד הכולל Base APK וכל קובצי ה־Split APK.
- ניסיון לגבות נתוני משתמש פרטיים דרך su כאשר Root זמין, או דרך run-as לאפליקציות debuggable.
- ניסיון לגבות Android/data, Android/media ו־Android/obb דרך Shell, עם ניסיון Root נוסף כשזמין.
- מניפסט הכולל package id, גרסה, חתימת APK, נתיבים, סוגי גיבוי, גדלים ו־SHA-256.
- שחזור ZIP באמצעות SAF ו־Wireless Debugging, כולל התקנת APK + Split APK כאשר היישום אינו מותקן.
- בדיקת חתימת APK לפני התקנה/שחזור נתונים.
- דיווח מפורש על נתונים שנכללו, הוחזרו או דולגו.

## מגבלות הרשאה חשובות
ADB Shell אינו עוקף את Android application sandbox. לכן:
- נתונים פרטיים ב־/data/user/<id>/<package> ניתנים לגיבוי/שחזור רק עם Root, או עם run-as כאשר האפליקציה debuggable ומאפשרת זאת.
- שחזור נתונים מגובים ב־Root מחייב Root גם במכשיר היעד.
- ללא Root ייתכן גיבוי חלקי בלבד. היישום מציג את המגבלות בדוח ואינו מציג גיבוי חלקי כגיבוי מלא.
- Android Keystore, מפתחות קשורים לחומרת המכשיר, נתונים מוצפנים הקשורים למזהה התקנה ותוכן שאפליקציה מאמתת מול שרת אינם מובטחים להעברה.
- קובצי נתונים מוחזרים רק לאחר אימות manifest, hash, נתיבי ZIP/TAR וחתימת היישום. קובצי TAR עם קישורים או נתיבים לא בטוחים נדחים לפני שחזור.

## כלי ADB שנשמרו
- חיבור/שיוך Android Wireless Debugging מתוך המכשיר.
- מסוף ADB ידני, היסטוריית פקודות ופלט.
- פעולות מהירות ופקודות מוכנות.
- מנהל אפליקציות: הסרה למשתמש הנוכחי, השבתה והפעלה.
- התקנת APK דרך ADB.
- סוכן AI שממיר בקשות בעברית לפקודות ומציג פעולות לא־קריאה לאישור.
- הגדרות ומפתחות API מוצפנים באמצעות Android Keystore.

## בנייה
ה־workflow בשם Build release APK מופעל בכל push ל־main או ידנית דרך GitHub Actions. הוא מריץ ./gradlew assembleRelease ומעלה APK כ־Artifact בשם ladb-hebrew-ai-release.
