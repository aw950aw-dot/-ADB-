# ADB חכם – ממשק עברי מבוסס LADB

האפליקציה משתמשת במנוע ADB האלחוטי של LADB (Tyler Nijmeh) ומוסיפה ממשק בעברית, פעולות מהירות, פקודות מוכנות, היסטוריה וסוכן Gemini שמציע פקודה לאישור המשתמש לפני ביצוע.

## בנייה
ה־workflow `Build release APK` מייבא את קוד מנוע LADB, מחיל את שכבת הממשק ובונה APK ב־GitHub Actions.

## AI
יש להוסיף מפתח Gemini אישי דרך הגדרות האפליקציה. המפתח נשמר מוצפן באמצעות Android Keystore. אין להכניס מפתחות API לקוד המקור או ל־GitHub.

## רישוי
מנוע LADB מבוסס על הפרויקט של Tyler Nijmeh. יש לשמור את הודעות זכויות היוצרים והרישיון המקורי של LADB ואת רישיונות התלויות.
