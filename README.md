# ADB חכם – גיבוי ושחזור אפליקציות + LADB

גרסה 1.6.0. אפליקציית Android בעברית המבוססת על מנוע ה־ADB האלחוטי של LADB. גיבוי ושחזור הם הפעולה המרכזית, וכלי LADB/ADB הישנים נשארו זמינים.

## גיבוי ושחזור
- מסך ראשי ייעודי עם שתי פעולות בלבד: גיבוי אפליקציה ושחזור מקובץ ZIP.
- בחירת אפליקציה ממסך רשימה עצמאי עם גלילה אחת לכל הרשימה, חיפוש והצגת אפליקציות מערכת לפי בחירה.
- יצירת ZIP הכולל Base APK, כל קובצי Split ונתונים שהמערכת מתירה לקרוא.
- גיבוי ושחזור נתונים פרטיים דרך הרשאת Root של האפליקציה, או באמצעות run-as באפליקציות debuggable.
- גיבוי Android/data, Android/media ו־Android/obb דרך ADB או Root.
- מניפסט עם package id, גרסה, חתימת APK, נתיבים, סוגי נתונים, גדלים ו־SHA-256.
- אימות חתימה, Hash, נתיבי ZIP/TAR, שמות כפולים ודחיית קישורים ונתיבים לא בטוחים לפני שחזור.
- יצירת ZIP זמני והחלפת קובץ גיבוי קודם רק לאחר יצירה מוצלחת.
- שחזור ZIP באמצעות SAF, כולל התקנת APK + Split APK אם היישום אינו מותקן.

## הרשאת Root
בהגדרות ניתן ללחוץ על בדיקת/בקשת Root. Android Smart מפעיל את su מתוך התהליך של האפליקציה, ומבקש הרשאה ממנהל Root כגון Magisk או KernelSU. הגישה נשמרת רק לאחר שהבדיקה מחזירה uid=0. ניתן לשנות או לבטל את ההרשאה דרך מנהל ה־Root.

Root נדרש לגיבוי או לשחזור נתונים פרטיים של אפליקציות רגילות. ללא Root, `run-as` זמין רק אם אפליקציית המקור debuggable ומאפשרת זאת. Android Keystore, מפתחות הקשורים לחומרה או למזהה התקנה ותוכן שאפליקציה מאמתת מול שרת אינם מובטחים להעברה.

## חיבור וכלי ADB
- מסך חיבור Wireless Debugging עצמאי עם הזנת קוד מהתראה, גילוי פורט אוטומטי ואפשרות לפורט ידני.
- שירות שיוך ברקע שמונע מהאפליקציה להסתיר את מסך הגדרות Android.
- מסוף ADB ידני, היסטוריית פקודות, פלט מוגבל וקריאה הדרגתית של פלט חדש.
- ניהול תהליכי ADB עם זמני המתנה, קריאת פלט במקביל וניסיון חיבור מחדש מבוקר.
- פקודות מוכנות, פעולות מהירות והתקנת APK.
- מסך ניהול אפליקציות עם בחירה נפרדת בין הסרה, השבתה והפעלה.

## מראה האפליקציה
הגדרה גלובלית לממשק כהה או בהיר. אותה בחירה חלה על מסך הבית, הגיבוי והשחזור, הגדרות, רשימות האפליקציות, פקודות ומסכי LADB הישנים.

## בנייה
ה־workflow בשם Build release APK מופעל בכל push ל־main או ידנית דרך GitHub Actions. הוא מריץ `./gradlew assembleRelease` ומעלה APK כ־Artifact בשם `ladb-hebrew-ai-release`.
